# Hsin Travel website

A bilingual travel and van rental enquiry website built with React and TanStack Start. Visitors can browse destinations and vehicles, then send a pre-filled enquiry through WhatsApp.

## Run locally

Install Node.js and npm, then run:

```sh
npm install
npm run dev
```

Open the local address printed by Vite. To check a production build, run `npm run build`.

Business contact details, WhatsApp messages, and site content are centralized in `src/lib/site-config.ts`. Image sources and usage are documented in `IMAGE-GUIDE.md`.

This is an independent website concept and is not an official Hsin Travel website.
